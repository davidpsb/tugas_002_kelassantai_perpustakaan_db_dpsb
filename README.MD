# Tugas REST API Perpustakaan

Dibuat menggunakan Flask, Flask-SQLAlchemy, dan MySQL.

## Cara Instalasi & Menjalankan

1. Clone repository ini.
2. Buat virtual environment: `python -m venv venv`
3. Aktifkan venv: `venv\Scripts\activate` (Windows)
4. Install dependensi: `pip install -r requirements.txt`
5. Buat database baru di MySQL dengan nama `perpustakaan_db`.
6. Sesuaikan konfigurasi database di file `perpustakaan.py` (user & password MySQL).
7. Jalankan aplikasi: `python perpustakaan.py`
